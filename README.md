# VisionLoop

Aplicativo web para espelhar a tela do dispositivo (celular/PC) para uma TV.

## 📋 Sobre o projeto

Breve descrição: como funciona, tecnologia usada (WebRTC, Cast API, socket, etc.),
e o problema que resolve.

## 🚀 Funcionalidades

- Espelhamento em tempo real
- Pareamento via QR Code / código
- Controle remoto pela tela do dispositivo
- Suporte a múltiplos dispositivos (se aplicável)
